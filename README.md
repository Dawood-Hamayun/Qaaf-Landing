# Qaaf Landing

Marketing site for **Qaaf — Learn 500 Quran words**.

Next.js 15 · App Router · Tailwind · Framer Motion · `next-themes`.

```bash
cd landing
npm install
npm run dev
```

The candlelight theme mirrors the mobile app: cream + amber in light mode,
deep ember + amber in dark. Fonts: **Fraunces** (serif headlines),
**Figtree** (body), **Amiri** (Arabic).
